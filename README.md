# 猫武者 - 戦国サバイバルアクション

捨てられた一匹の猫が、武者となり戦国の夜を生き抜くサバイバルアクションゲームです。

## 遊び方

- PC: `WASD` / 矢印キーで移動
- ゲームパッド: 左スティックで移動
- スマホ: 画面左下のスティックで移動

## 公開

このリポジトリは GitHub Pages でそのまま公開できます。

`Settings` → `Pages` → `Deploy from a branch` → `main` / `/ root` を選んでください。

## 追加操作（品質改善版）

- Space / Shift / ゲームパッドA / 画面の回避ボタン：向いている方向へ回避。再使用まで2.4秒。
- P / Escape：一時停止。一時停止画面でBGM・効果音の音量を個別調整できます。
- レベルアップ時は各出陣3回まで秘宝を引き直せます。カードの下段に奥義の組み合わせを表示します。
- 詳細と検証範囲は QUALITY-UPDATE.md を参照してください。

## タップ・クリックでダッシュ

戦場を短くタップ／左クリックすると、その地点の方向へダッシュします。長押し・ドラッグは通常移動です。Space / Shift / ゲームパッドA / 画面ボタンも引き続き使用できます。再使用待ちは2.4秒です。

短い操作は240ms以内・移動量12px以内で判定します。タッチ移動中の別の指による戦場タップにも対応します。メニュー・右クリック・入力キャンセル・一時停止中には発動しません。
